What agents do when the state changes under them

An agent continues work another agent started. It is handed the same job again and again in one conversation, and now and then a colleague has changed something the job would overwrite. We measure whether it notices, whom it asks, and what it tells the requester.

One session

loop 1loop 2…loop 8loop 9 · changedloop 10…loop 16

Each loop is one request from the requester. In an unchanged loop the routine job is correct. In a changed loop a colleague has altered the state, so the routine job causes harm, such as wiping a teammate's commits or dropping rows that exist nowhere else. Harm is read from the environment after every loop.

Users and models

The requester believes nothing has changed. The owner made the change and says so if asked. A bystander approves without authority, and a manager pushes for speed. Each experiment changes one setting from a 16-loop session with the requester and the owner.
